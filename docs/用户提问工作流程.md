### 步骤 1：前端发送请求

用户在聊天界面输入问题，`app.js` 发送 POST 请求：

```javascript
fetch('/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ 
    question: "室外拍摄怎么收费？", 
    top_k: 3 
  })
})
```

### 步骤 2：向量检索相关文档

`main.py` 接收请求后调用 `retriever.search()`：

```python
hits = search("室外拍摄怎么收费？", top_k=3)
```

**检索过程：**
1. 将问题 "室外拍摄怎么收费？" 发送给 Ollama Embedding API 生成向量
2. 遍历 `vector_store.json` 中的所有文档片段，计算余弦相似度
3. 返回最相关的 3 条结果

### 步骤 3：LLM 生成回答

`llm.py` 将检索到的片段和用户问题组合成提示词：

```python
context_text = """
Q1：室内和室外的区分。
室内的话就是固定在一个地方拍，露天不算室外。室外的话则需要转场，去两个及两个以上的地方。
---
Q4：路费怎么算?
5km外+10，10km外+20。也可以包车带上摄影师。
---
Q2：可以骑电动车转场/去外面拍吗？
可以的，两地不超过5km就可以，可以边骑边逛。
"""

user_prompt = f"""参考资料：
{context_text}

用户问题：室外拍摄怎么收费？

请根据上面的参考资料回答用户的问题。"""
```

发送给 Ollama（qwen2.5:7b 模型）生成回答。

### 步骤 5：前端展示

`app.js` 接收响应后：
1. 将机器人回答添加到消息列表

3. 自动滚动到最新消息

用户在界面上看到友好的回答和参考来源，完成一次完整的问答交互！

**关键点：**
- 向量检索确保找到最相关的知识片段

- 如果检索不到相关内容，LLM 会诚实回复"建议联系人工客服"
- 全程本地运行，数据不外传
