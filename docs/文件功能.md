好的，这是一个基于 RAG（检索增强生成）的智能客服系统。让我为你解释各个文件的作用：

## 📁 项目结构说明

### 后端部分 (`backend/`)

**main.py** - FastAPI 主入口
- 提供 `/chat` 接口处理用户问题
- 提供 `/health` 健康检查接口
- 托管前端静态文件服务
- 配置 CORS 跨域支持

**retriever.py** - 向量检索模块
- 使用 Ollama Embedding API 生成文本向量
- 用 JSON 文件存储向量数据（轻量级方案）
- 实现余弦相似度搜索
- 提供 `insert()` 写入文档、`search()` 检索相关内容

**llm.py** - 大语言模型调用
- 封装 Ollama API 调用
- 定义客服助手的系统提示词（要求友好、准确、基于参考资料回答）
- 将检索到的文档片段作为上下文传给 LLM

**ingest.py** - 离线数据导入脚本
- 读取 txt 文件并分块（支持滑动窗口 overlap）
- 将文本片段向量化后写入向量库
- 支持单文件或批量处理整个文件夹

**requirements.txt** - Python 依赖
- FastAPI、Uvicorn（Web 框架）
- Requests（HTTP 调用）
- Pydantic（数据验证）

**Dockerfile** - 容器镜像构建
- 基于 Python 3.11
- 预下载 embedding 模型加速启动

**docker-compose.yml** - 容器编排配置
- 定义服务端口映射（8000）
- 挂载前端、文档、向量数据卷
- 配置 Ollama 连接地址和模型名称

### 前端部分 (`frontend/`)

**index.html** - 单页应用界面
- 现代化聊天 UI 设计
- 使用 Vue 3 CDN 版本
- 包含欢迎页、快捷问题按钮、消息气泡、输入框

**app.js** - Vue 3 前端逻辑
- 管理聊天消息状态
- 调用后端 `/chat` 接口
- 处理加载状态和错误提示
- 自动滚动到最新消息

### 数据部分 (`data/`)

**docs/faq.txt** - 知识库文档
- 存储客服问答内容（当前是摄影服务相关的 FAQ）
- 通过 `ingest.py` 导入向量库

### 其他文件

**.gitignore** - Git 忽略规则

**photoservice.db** - SQLite 数据库文件（可能是历史遗留，当前代码未使用）

**vector_store.json** - 向量数据存储（由 `retriever.py` 生成和使用）

## 🔄 工作流程

1. 离线阶段：运行 `ingest.py` 将 FAQ 文档向量化存入 `vector_store.json`
2. 用户提问 → 前端发送到 `/chat` 接口
3. `retriever.py` 检索最相关的 3 条文档片段
4. `llm.py` 将片段和问题发给 Ollama 生成回答
5. 返回答案和来源文件名给前端展示

这是一个轻量级、零编译依赖的 RAG 方案，适合快速部署本地知识库问答系统。
