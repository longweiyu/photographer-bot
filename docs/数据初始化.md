好问题！`vector_store.json` 的数据是通过 **离线脚本 `ingest.py`** 初始化的。让我详细说明这个过程：

## 📝 初始化流程

### 第 1 步：运行导入脚本

在命令行执行：

```bash
python backend/ingest.py --input ./data/docs/faq.txt
```

或批量导入整个文件夹：

```bash
python backend/ingest.py --input ./data/docs/
```

### 第 2 步：读取并分块

`ingest.py` 会：

1. **读取 `faq.txt` 文件内容**

```python
text = read_txt("./data/docs/faq.txt")
# 得到完整文本内容
```

2. **智能分块**（默认每块 300 字符，重叠 50 字符）

```python
chunks = split_text(text, chunk_size=300, overlap=50)
```

**分块示例：**

根据你的 `faq.txt`，可能会被分成这样的片段：

```python
[
  "Q1：室内和室外的区分。
室内的话就是固定在一个地方拍，露天不算室外。室外的话则需要转场，去两个及两个以上的地方。\n\nQ2：可以骑电动车转场/去外面拍吗？
可以的，两地不超过5km就可以，可以边骑边逛。",
  
  "Q2：可以骑电动车转场/去外面拍吗？
可以的，两地不超过5km就可以，可以边骑边逛。\n
八点半前需要早起费30。\n
Q4：路费怎么算?\n5km外+10，10km外+20。也可以包车带上摄影师。",
  
  "Q4：路费怎么算?
5km外+10，10km外+20。也可以包车带上摄影师。

Q5：怎么预约？
以付定金为准，才算预约，口头预约几号不算。

Q6：付完定金后涨价？
付定金后涨价，仍按付定金时价格计算。"
]
```

注意 **overlap=50** 的作用：相邻块之间有重叠部分，避免重要信息被截断。

### 第 3 步：调用 Ollama 生成向量

```python
insert(chunks, metadatas=[{"source": "faq.txt"}] * len(chunks))
```

`retriever.py` 的 `insert()` 函数会：

1. **批量调用 Ollama Embedding API**（每次 10 条）

```python
# 发送 HTTP 请求到 Ollama
POST http://localhost:11434/api/embed
{
  "model": "nomic-embed-text",
  "input": [
    "Q1：室内和室外的区分...",
    "Q2：可以骑电动车转场..."
  ]
}
```

2. **Ollama 返回向量**（每个文本片段对应一个高维向量）

```python
{
  "embeddings": [
    [0.123, -0.456, 0.789, ..., 0.234],  # 768 维向量
    [-0.321, 0.654, -0.987, ..., 0.111],
    ...
  ]
}
```

### 第 4 步：保存到 JSON 文件

`retriever.py` 将文本、来源、向量一起存入 `vector_store.json`：

```json
{
  "documents": [
    {
      "text": "Q1：室内和室外的区分。\n室内的话就是固定在一个地方拍...",
      "source": "faq.txt",
      "vector": [0.123, -0.456, 0.789, ..., 0.234]
    },
    {
      "text": "Q2：可以骑电动车转场/去外面拍吗？
可以的，两地不超过5km...",
      "source": "faq.txt",

    },
    {
      "text": "Q4：路费怎么算?\n5km外+10，10km外+20...",
      "source": "faq.txt",
      "vector": [0.555, 0.222, -0.333, ..., 0.888]
    }
  ]
}
```

## 🔄 后续使用

初始化完成后，`vector_store.json` 就包含了所有文档的向量表示。

当用户提问时：
1. 问题也会被转成向量
2. 与 JSON 中每个文档片段的向量计算余弦相似度
3. 返回相似度最高的 top_k 条结果

**关键点：**
- 只需要运行一次 `ingest.py`（除非更新知识库）
- 向量化是离线完成的，不影响在线查询速度
- 使用 JSON 存储简单直接，适合小规模数据（几千条以内）

如果你想重新初始化或更新知识库，只需修改 `faq.txt` 后重新运行 `ingest.py` 即可！
